Original Array

Spliced Array

splice(2): remove all elements starting at index 2

splice(1, 2); remove 2 elements starting at index 1

splice(0, 0, 6); remove 0 elements at index 0 and add 6

splice(1, 0, "green", "yellow"); insert at index 1 without removing

splice(1, 2, 99, 100); remove 2 elements at index 1, add 99 and 100

splice(-2, 1); remove 1 element from index -2

Slice The Array

slice(1, 3) extracts elements from index 1 up to, but not including, index 3.

slice(-2) extracts the last two elements of the array.
